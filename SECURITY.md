# Security Policy

## Supported Versions

Chronicled is an actively developed project, and security fixes are handled on a best-effort basis.

Unless otherwise stated in a release announcement, please report security vulnerabilities affecting the latest version of Chronicled. Older versions may not receive security updates.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or pull requests.**

The preferred reporting method is GitHub's private vulnerability reporting feature:

1. Visit the [Chronicled repository](https://github.com/kianelbo/chronicled).
2. Open the **Security and quality** tab.
3. Select **Report a vulnerability**.
4. Provide enough information for the maintainers to understand, reproduce, and assess the issue.

Reports submitted through this feature are private and are visible to the maintainers through GitHub's security advisory workflow.

If private vulnerability reporting is unavailable, please contact the maintainer privately through an appropriate contact channel rather than disclosing the vulnerability publicly.

## What to Include

When reporting a vulnerability, please include, where possible:

- A clear description of the vulnerability.
- The affected version, component, endpoint, or configuration.
- The potential security impact.
- Reproduction steps or a proof of concept.
- Any relevant logs, requests, or screenshots, with secrets and personal information redacted.
- A suggested mitigation, if you have one.

Please avoid including real credentials, access tokens, production data, or other sensitive information in your report.

## Disclosure and Response

Please allow the maintainers reasonable time to investigate, develop a fix, and coordinate disclosure before publishing vulnerability details.

The maintainers will make a best-effort attempt to acknowledge reports, assess their severity, and communicate next steps. Response and remediation times are not guaranteed.

Once a vulnerability has been addressed, relevant details may be disclosed through a GitHub Security Advisory, release notes, or another appropriate project announcement.

Thank you for helping keep Chronicled secure.
